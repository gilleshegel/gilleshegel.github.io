## 定义
角色进行行动的最基本单位。由一个施放技能者触发。

必须包含：
- 范围：近程、远程、自己。
- [[元素]]：匮乏、流变、完满、无。
- [[属性]]：力量、智力、敏捷、洞见、魅力、体质。根据施放技能者的属性获得属性调整值
- 基础骰子：与武器相关或无关
- 使用条件：如需要一把剑、需要空手、消耗精力点
```
示例（数值不是定下来的）

技能名：斩击
描述：近程/A/力量。使用利器迈步向前，对单个敌人造成基础2d3的伤害。
（对于双手战士：A类型/力量。使用一把剑，对单个敌人造成基础2d4的伤害)

技能名：火球术
描述：近程/B/智力。聚集轻盈者并喷发，消耗1个精力点，对单排敌人造成基础2d3的伤害。

技能名：治疗术
描述：近程/无/洞见。凝结活力并冲击灵魂，消耗1个精力点，对单个队友造成基础1d6的恢复。

技能名：流溢血祭
描述：自己/无/魅力。以爪贯穿心脏连结本源，失去2d4点血量，获得持续3回合的buff“流溢”，期间你的B元素伤害获得额外的魅力调整值。

技能名：某种民谣
描述：近程/C/魅力。演奏弦乐器，调谐悲伤与灵魂的共振，对单个敌人施加状态“痛苦”
```

根据功能，可以大致将技能分为：**攻击技能**、**辅助技能**。凡是对敌人造成伤害的，就是攻击技能；否则是辅助技能。

### 攻击技能
攻击技能造成伤害。计算公式：
$$
伤害 = max(1, 基础骰子 + 属性调整值 - max(0,基础防御+抗性防御-破甲) )
$$

基础骰子：技能决定
属性调整值：技能决定。一般是（属性-10）/2，底除
```
示例

技能名：斩击
描述：近程/A元素/力量。使用利器迈步向前，对单个敌人造成基础2d3的伤害。
场景：一个18力量的战士，对一个0基础防御、1 A元素抗性的敌人使用斩击。
计算：伤害 = max(1,2d3+4-max(0,0+1-0)) = max(1,2d3+3)

技能名：凌迟
描述：近程/C/敏捷。使用利器灵巧地刺伤敌人，消耗1个精力点，对单个敌人造成基础2d2的伤害，附加持续3回合的buff“流血”，期间敌人每回合受到基础1d2的伤害。
```

### 辅助技能
辅助技能造成各种效果。若效果涉及量，计算公式：
$$
量 = max(1, 基础骰子 + 属性调整值 )
$$

```
示例

技能名：治疗术
描述：近程/无/洞见。凝结活力并冲击灵魂，消耗1个精力点，对单个队友造成基础1d6的恢复。
场景：一个16洞见的牧师，对一个队友使用治疗术。
计算：量 = max(1,1d6+3)

技能名：护盾术
描述：近程/无/智力。凝结回忆并塑形为盾，消耗1个精力点，使得单个队友获得持续2回合的buff“护盾”，期间ta的基础防御值+1。
场景：一个18智力的法师，对一个队友使用护盾术。
计算：没有涉及到量。
```
### 精力点
精力点是技能消耗的一种额外的资源，来自于施放技能者。
```
示例
技能名：治疗术
描述：近程/无/洞见。凝结活力并冲击灵魂，消耗1个精力点，对单个队友造成基础1d6的恢复。

技能名：跳劈
描述：近程/B/力量、敏捷。驾驭疾风以剑猛袭，消耗1个精力点，对单个敌人造成基础2d4的伤害，额外附加敏捷调整值。
```
