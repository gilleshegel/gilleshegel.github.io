# 前言
这是一篇用于让任何一个参与各各他林项目开发的成员快速了解世界观**设计**上的思路的文章。
# 一、创作史
各各他林有不止一个前身的版本，以下命名为：
- 古早版：2024年三人跑团的版本，别名自身亵渎之国。
- 原案版：2025年五人跑团的版本，别名被启示的国度。
- 现版本：本项目的版本，没有别名，直接叫“各各他林”就可以了。
## 古早版
古早版是出于对渎神的喜爱、对神界原罪2的世界观的兴趣、对《剑风传奇》断罪塔篇的兴趣而创作的，机制完全基于四战黑。
古早版的核心创作理念是**后冒险**，即围绕**在已经无可冒险的情况下，还能产生怎样的冒险**这个主题的，而不是任何道德、伦理的主题。这个理念基本是三版本的支柱，虽然现版本做了一些修改。
但是，古早版同样有着宗教方面的主题，借鉴极乐迪斯科和渎神，古早版的世界（阿莱夫）是一个**濒死**的世界，并且人们在这个世界之下理智逐渐崩溃，变得极端、疯狂，是以这个项目被我称作**自身亵渎之国**，即一个亵渎着自己的国度。

古早版基本没有任何世界观设计，就是很单纯的宗教猎奇+黑暗奇幻。
- 绝大多数要素都来自渎神1。
- 有瘟疫，但是没有任何着色，这个瘟疫也不涉及任何魔法。
- 没有**圣教**这个东西，只有**如一教**。这是一个新柏拉图主义的宗教，信奉所谓的**太一**。这个宗教的文本有一篇，叫《如一是颂》，它的文本部分地修改为现版本的一个文本《至上颂》。这个宗教也没有任何道德上的倡导，可以说就是刻板印象中的新教。
- 并没有任何意义上的真正的神祇存在，但是有一个客观衡量玩家善恶的物品“荆棘”，它基本是渎神1的“古斯托迪亚的罪孽”的翻版。
- 主要的敌对势力是**拜火教**，信仰**拜火邪神马自达**。拜火教就是很刻板印象的邪教，有一个入会的门槛：申请者需要提交由人肉加工而成的**礼物**，这个东西是可以偷的。拜火教很大程度上是《剑风传奇》断罪塔篇的那个秘密邪教的改良版。

古早版有一些有特色的角色，很多其实都是一拍脑门想到的
- 死人头约翰。一个boss奖励，屁话很多，是我当时用来协调跑团的不可控程度的道具，比如在某处明确说“啊这里是线索”，或者“这里不能走，是因为...”。
- 约拿王是驻扎在各各他林的如一教领袖，也是约翰的兄弟。这个角色在当前版本就是一个虔诚的如一教信徒，没什么道德，比邪教徒强一些。
- 伪装成圣音的骗子侏儒。他的原型是渎神2的一个npc。这个家伙是一个单纯的特殊房间的npc，没有任何特殊剧情。
- 早就疯掉了的牧师何塞。这个角色是瓦伦缇娜的原型。他可以入队，且san值是异常的（数值很高，且san check之后加减是随机的），在一定进度时彻底疯狂，袭击玩家。

古早版是一个跑团剧本，所以并没有给太多的限制
- 玩家是前冒险者，参加了**百年战争**，被受膏者阿尔卡蒂奥派来处理邪教危机，且明确地是被兔死狗烹。
- 玩家首先来到所谓的**宁诺戴尔城**，这个名字来自我听Camel《White Rider》看到的名字宁诺戴尔，出自指环王，大概是某一条河的名字。
- 各各他林就是各各他林，没有前身。
- 宝物、敌人都高度参考了博尔赫斯。
- BOSS包括：柳条人，七剑怨女，鼠王，铁处女妖花，拜火圣父，拜火邪神马自达，约拿王，末日圣子各各他
- 有三个结局：打败拜火邪神马自达，打败约拿王，打败二者的合体**末日圣子各各他**。这里有一个明确的主题，即两种宗教其实殊途同归，只有战胜这种宗教精神才能获得胜利。
- 在结束了各各他林的旅程后，玩家会进入下一个阶段，即**橄榄修道院**。实际上整个项目有多个步骤，包含多个地图，比如完全照搬渎神的神圣禁忌之墙，因为我当时以为高三期间能跑很多次。实际上并没有。
- 这个项目的歌单参见 https://music.163.com/m/playlist?id=10072153698&creatorId=1353180364

## 原案版
在完整游玩神界原罪2、博德之门3，且阅读了一些神学、宗教相关著作后，我对奇幻世界观有了更多的想法，实际上更往crpg，而不是银河恶魔城的方向修正。当然了，有这个版本只是因为当时大家想跑个团。
原案版的大部分剧情都保留在现版本了。
相比于古早版，原案版有更丰富的世界观参照和表达
- 原案版的宗教、神话理论借鉴了**中期谢林**，相关著作《世界时代》、《自由论文》。
- 原案版大幅提升了对博尔赫斯的引用。额外添加了大量对拉伯雷《巨人传》的引用。
- 原案版提升了对**后冒险**的戏谑，具体表现参照后文。
- 一个很搞笑的事实，原案版其实一定程度上参照了我24年对元气骑士的拓展。非小学生应该一般不思考这种东西。
- 原案版包含很多对我之前的跑团角色的利用，即奥雷良诺、马丁费耶洛。这两个角色是之前的几次跑团中我扮演的角色。

原案版继承了古早版的两大主题，**后冒险，濒死**。并且，原案版强化了古早版对渎神世界观**奇迹**的化用，在原案版里，没有明确的神祇，只有**纯粹的信仰**带来的力量，无论信仰什么东西。这个设定当然还参考了一些克尔凯郭尔，写作古早版时我已经有这个打算了，但没有付诸实践。

- 阿莱夫是费伦大陆的一个国家。
- 阿莱夫的历史分为两段，第一段是正统的DND世界，第二段则是原案版的原创版本。两个版本以**旧神的死亡**和**新神的创生**为分界线。根据这个分界，我滑稽地用**被启示的国度**来称呼第二段故事，用来对照DND正统的名词**被遗忘的国度**，以表明：旧神和旧世界的历史被遗忘了，真正的新神的启示取代了前者。

原案版圣教神话
**一、被遗忘的国度**
千年以前，密斯特拉的密仪尚未失传，神谱维持在前所未有的华丽与喧嚣中。那时的诸神之神艾欧创造了世间万物并维系着神与凡人的平衡。如今我们回顾这一永恒流逝的过去，却不清楚为何艾欧离去，也不清楚真正的神系为何，我们最终只能整理出一套能发展为现实的神谱。
那一时代的绝大多数硕果都已枯朽，我们称之为“被遗忘的国度”

a.肯定者塞伦涅
艾欧创世伊始，纯净而善良的光成为肯定者，月之少女塞伦涅，她温柔、慈祥并肯定万众分殊。

b.否定者莎尔
然而有光就有暗，有肯定就有否定，混沌而邪恶的暗成为否定者，暗夜女神莎尔。她是塞伦涅的妹妹，与塞伦涅完全对着干。据说被遗忘的国度中的光暗循环就是二者争斗的显像。

c.诸神
在原初的双子的争斗中，艾欧那满溢的神性继续扩散着，万事万物都开始具有自身的神祇。洛山达、裳提娅、海姆...双子支配世界的时代很快就过去的，诸神的时代开启了。

d.大全一体密斯特拉
然而诸神并不满足于一种脱离了秩序与荣光的世界，他们渴望成为父祖艾欧，神性与力量凝聚，最终成为了所谓的大全一体：魔法女神密斯特拉。密斯特拉既是唯一掌握被遗忘国度魔网者，又是诸多神祇之魔力的整全。

e.万物终焉耶格
不知何时，艾欧遗忘了这个世界，离去了。自艾欧离去后，神性就开始枯竭，或者说，按照如今的观点来看，神性开始回归纯净。然而这对诸神而言不是好事。神性的丧失意味着神的死亡。
最终诸神陷入死亡，唯独耶格，死亡本身，留存。然而在失去任何神格的时刻，死亡之神这一概念还会成立么？在无神可死的情况下，无死可记录的情况下，耶格弥散了。
自耶格弥散后，万物溃败，神性终于回归本身，等待自身的启示。


**二、被启示的国度**
国度之分的实质是神的区分。被遗忘的国度中，真神尚未被启示，毋宁说被遗忘了，与旧神系的命运何其相似。而新世界中的真神成功启示自身，并创造出如今的世界，以生命反映自身，所以叫被启示的国度。
在这之后不再有诸神，而只有唯一的真神，但祂直到完满之前都没有意识到自己是唯一的真神。

a.心灵之神
纯净、无辜的神性无所欲求、无所失衡、无所分歧。但它保持着神性本真的品性：创造。这一神性创造崭新的事物、改写现实的规律，这就是为何在大崩溃时期旧时代的生命和魔网崩溃，转而以新的规律彰显出来。这一神性不仅创造一个对象，祂还关切着它，仿佛它是自己的孩子一般。
这一无私而纯真的神性于是将创造的品性体现为一种神格，继而成为一个神。在圣教未组织时，祂有诸多名称：慈爱者、流溢者、关切的神，如今我们统一称为心灵之神。

b.灵魂之神
然而我们都知道，一个单纯投注于对象的东西是不可能作为一个独立的东西存在的，它必须意识到自身。这对心灵之神来说也是同样适用的：当祂意识到自己的神格并不代表自己是神时，祂就会试图找到一条道路，方法也很简单：从投注于它物到投注自身。
然而投注自身时，心灵之神就将自己把握为两个东西：一个是进行投注的自己，一个是被投注的自己。任何一种投注都必然带来这二者的分歧。这一分裂是原初的、不可避免的、罪恶的。
当心灵之神投注自己并把握到自己时，这一裂缝、罪孽与它共享同等的神性（毕竟祂们说到底都是同一个神性的行为），成为了一个独立的神。祂同样有诸多名称：自为者、孤立者、罪恶的神，如今我们称之为灵魂之神。

c.大流变
心灵之神与灵魂之神虽是同一神性却不是一个神，祂们的神格是大相径庭的，这就使得祂们进入了争吵。不少人以为这是重演了塞伦涅和莎尔的争斗，但实际上并不是的。
因其本性和成神的需要，心灵之神与灵魂之神争斗，也就是说祂们需要对方作为投注对象，才能把握到自己，因此这个争斗是内在于神性的。类似于投注产生的分裂因其内在于神性而成为神，这个争斗也是内在于神性的，所以祂也是一个神。这就是第三者。争斗者、魔网蜘蛛、酒神、物质因，我们如今统一称为大流变。之所以不称为“流变之神”，是因为民俗传统和英雄神话中大流变这个说法普遍流传并深入人心。

d.启示之轮
也许有人说，现在是三个神在争斗了，是不是这个争斗本身也是一个新神，如此以致无穷？这就没有理解三个神的神格。心灵之神代表着最纯净的创造，或者心灵活动，以及过去；灵魂之神代表最痛苦的罪孽，或者孤立的灵魂，以及未来；大流变代表着这两种力量之间的争斗，囊括了世间万物即魔法-物质的交互转换，还有现在。这已经是一个充盈着的体系了，没有更多的神格。
但是这不意味着三个神不争斗了。相反，既然神性已经被三个神格充满而祂们彼此不满，那就会争夺谁才是唯一者。祂们的争斗是如此激烈，每当某个神祇登上神座，其余两个神就会立刻把祂拉下来，以至于形成了一个争斗的循环，一个疯狂的轮子。
然而这个轮子丝毫不意味着痛苦、绝望，相反，神性的疯狂对神而言是颇有益处的，祂使得神可以思考，自己的神力如何要与自己的神性意志协调，以至于祂们要与其余的神相协调。也就是说，这是一个启示之轮。
就在这一过程中，无数英雄人物蒙蔽启示之轮带来的神性光辉，要么成为传奇冒险者，要么被误以为是新神（这在民俗信仰中十分常见，但圣教已经纠正了这一点），要么已经预料到启示之轮的结果并成为圣徒。

e.至大者
当三神完全地启示自身，即在争斗和疯狂中统一了自己的神力和神性意志，祂们就都意识到，自己并不是真神，而仅仅是神性，或者说，神的王座。在彻底发挥自己神性的本质后，三者迎来了真正的启示，即真神的降临。这个真神就是至大者。
至大者是统摄三者的真神，也是乘坐三者的君王，三者交相成为至大者的宝座，使得神与神性协调并满溢荣光。
这就是整个神话故事的结尾了。

# 二、世界观
## 2.1 游戏的主题
各各他林有着以下主题：
- 后冒险：一种根据正统冒险而被定义的独特的冒险，它是一个**被过去的冒险纠缠**的冒险，本身并不正统，甚至表现出一种对正统冒险的病态模仿。这个冒险的目的就是消解自己，冒险者最终只有放下冒险的幻想，才能获得解脱。这是一个纯粹基于冒险作品提出的概念，且高度受**剑风传奇的黄金时代篇**的影响：紧接着黄金时代的迷失的孩子、断罪塔（前中期）表现出了类似的主题，格斯被往日的梦幻纠缠着战斗，无法从痛苦和孤独中抽身。我个人并不喜欢这个主题被等同于任何一种**末日冒险**，末日冒险仅仅在基调上是与后冒险类似的，其实很正统。后冒险需要无时无刻不被理想的冒险纠缠，仿佛自己是后者的投影、不完美的拟像。
- 对过去的和解：作品难免包含着作者本身的历史，我个人是一个怀旧情结略重的人，在后冒险的基础上添加了
- 信徒得不到神的回应，该怎么办：这是一个很标准的神学话题，也是现版本独有的。实际上，这个主题是现代性的一大主题，只不过它更为人熟知的是无神论的版本，**没有神的时代（譬如，上帝已死），人类该怎么生存**。事实上，文本内大多数围绕这个主题的讨论都是无神论版本的改造版。世界观也不会给出明确的**这个世界有没有神**的回答。
- 形而上学风味：这是我个人非常喜欢的主题。我个人认为，一个好的奇幻世界观不能基于mana一般，或某种基本力量，来建构，这些都使得世界观不得不把魔法当作某种玄幻的学科，或者其实就是神棍版本的热机学说。出于我个人对知识、逻辑和认知的理解，我认为一个好的世界观应当有和现实的哲学一般丰富且严格的魔法学问，且这个学问和物理学的地位是同等的，你可以说这是一种Wissenschaft，它兼有science和sophia的含义。

## 2.2 游戏的故事
参见剧情大纲。
相比于原案版，现版本无疑是更加完善且有根据的。我在此补充一些关于现版本故事的讨论。
游戏中的几大势力，都是围绕着**如何面对至上者的沉默**的解答。
- 听义派（苦痛兄弟会）：相信神提供了回应，但是无法靠任何世俗知识理解。它只能靠苦修或神性体验获得。
- 苏生教：完全的放弃和享乐。在没有神的情况下，一切都是被许可的，所以可以随意放浪形骸。他们信仰的神，也不是一般意义上的神，而是被神圣化的纵欲行为。
- 行会：行恶的自由。在没有神的情况下，自然没有善，行恶、自私都是被允许的。
- 高朗古杰：自由的信仰是脆弱的，它没有牵涉到具体的利益，无法许诺任何东西，除非有奇迹降临。但是，神既然不愿意降下奇迹回应人们，人们就会无法获得生存的理由，或无法维持伦理。教廷就只能靠权威和压迫来保证伦理，以至于就算神真的降下了奇迹，只要这个奇迹威胁了教廷，它就要被反对。这个讨论出自陀思妥耶夫斯基《卡拉马佐夫兄弟》的“宗教大法官”。
- 游戏预期的一个回答：改编自**晚期谢林**（还有荷尔德林，但是和荷尔德林的差距过于大了）。人没办法承受神性的丰盈，也没办法得到神祇的回应，他们只能忍受自己的有限性；但是，在对有限性的接受下，人承认了自己相对于一个主宰的卑微，在这个行动中人才真正理解了超越性，并靠对这个主宰的信仰生存下去，尽管人依旧无法得到神的回应，只能孤独地行走在无神的黑夜里。demo不考虑这个主题的任何表达。

## 2.3 游戏的哲学参考
现版本的各大势力主要具有伦理的表达，而不是存在论的、神学的表达，因为伦理的切近人的生活，也更容易为观众在艺术中接收。美当然不是我们的便宜游戏能表达的。
以下讨论的却恰恰是存在论的、神学的表达，且基本不会具体说怎么参考了（不然很麻烦）。伦理的部分前面已经介绍过了。

圣教的所有理论有三位哲学家参考：亚里士多德、阿奎那、晚期谢林。灵魂学说基本就是亚里士多德的灵魂学说，但是添加了后来经院哲学的一些讨论，比如理智实体的不朽性。关于神的讨论则完全是晚期谢林的潜能阶次学说的翻版。

苏生教虽然是基于恐怖电影中的凯尔特文化设计的，但是本身也是有一定的参考的：狄俄倪索斯秘仪、厄硫希斯秘仪。值得一提的是，苏生教还参考了诺斯替主义（它污蔑圣教信仰的是假神），但是这一点纯粹是因为邪教反过来指责圣教信仰坏神很有趣，也是很常见的表达，而诺斯替擅长这个。

阿莱夫存在论的三重原理，匮乏、流变、完满，实际上对应的是亚里士多德的三个概念：褫夺、变化、实现。之前讨论元素设计时我最推荐的就是这个，但是反响并不好，只好找一些看起来牛逼一点的近义词。

## 2.4 游戏的文化参考
首先，各各他林不做鉴证。在游戏里鉴证并非不可，只是需要有水平，而很少有游戏有水平地鉴证。

阿莱夫原本是一个纯粹虚构的世界观，随着版本推进，我为它添加了很多拉丁美洲的主题。
现版本的一个重要的对立，保礼派-听义派，很容易让人想到天主教-新教的对立。然而，这个对立事实上是根据我在《百年孤独》里看到的保守派-自由派的对立写出来的。
游戏还大量借鉴了20~21世纪流行文化，包括摇滚、电影、电子游戏。这对于一个西方奇幻游戏来说不一定是好事。
